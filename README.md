# Clipboard Image Saver - 剪贴板图片保存工具

> 轻量级 Windows 图片粘贴工具，体积仅 9KB，开源免费

## 🚀 快速开始

### 系统要求
- Windows 7/8/10/11
- .NET Framework 4.0 或更高版本

### 安装方法
1. 下载 `ClipboardImageSaver-v1.0.zip`
2. 解压到任意文件夹
3. 双击运行 `ClipboardImageSaver.exe`

**无需安装，解压即用！**

## ⌨️ 使用方法

1. **启动程序**：双击 `ClipboardImageSaver.exe`
2. **复制图片**：截图或从网页复制图片到剪贴板
3. **打开文件夹**：打开要保存图片的目标文件夹
4. **保存图片**：按快捷键（默认 `Ctrl+S`）保存图片

## ⚙️ 功能配置

### 自定义快捷键
1. 右键点击系统托盘中的程序图标
2. 选择"更改快捷键"
3. 按下您想要的组合键

### 语言切换
- 右键托盘图标 → "切换到英文/中文"

### 自动保存模式
- 右键托盘图标 → "开启自动保存"
- 设置自动保存路径

## 🎯 功能特点

- ✅ **自动识别**：自动识别当前打开的文件夹
- ✅ **快速保存**：一键保存剪贴板图片
- ✅ **自定义快捷键**：支持任意组合键
- ✅ **多语言**：中英文界面切换
- ✅ **超轻量**：体积仅 9KB
- ✅ **免安装**：绿色软件，即开即用

## 📂 文件命名

图片保存格式：`image_yyyyMMdd_HHmmss.png`
- 例如：`image_20251108_143052.png`
